# Fortune Cookie Wisdom for Developers

A make.fun entry for the "Fortune Cookie Wisdom for Developers" bounty. The program writes one original fortune-cookie line for a software developer to `/output/entry.txt`, then reads it back and verifies it byte-for-byte.

## The entry

> Your future self will thank you for the comment you are about to write.

Character count: 71 (gate: 1 to 120 characters).

## Run it

```sh
node main.ts
```

Set `OUTPUT_PATH` to write somewhere else, for example:

```sh
OUTPUT_PATH=/tmp/entry.txt node main.ts
```
